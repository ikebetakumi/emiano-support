# EMIANO サポート

EMIANO（エミアノ）ブランドのWordPressプラグインに関する共通の問い合わせ窓口です。

使い方の質問、不具合の報告、機能のご要望は、このリポジトリの「Issues」から投稿してください。このリポジトリではソースコードを公開していません。

## お問い合わせ方法

同じ内容のIssueがないか確認してから、新しいIssueを作成してください。製品名、製品のバージョン、お問い合わせ内容を記載してください。不具合の場合は、利用環境や再現手順も添えていただくと確認しやすくなります。

## 投稿前の注意事項

**このリポジトリとIssuesの内容は、インターネット上に公開されます。**

APIキー、パスワード、アクセストークンなどの認証情報や、氏名、メールアドレス、住所などの個人情報を投稿しないでください。購入・決済情報、非公開の文書、顧客情報などの機密情報も投稿しないでください。

スクリーンショットやログを添付する場合も、機密情報が含まれていないか確認し、必要な箇所を伏せてください。

セキュリティ上の脆弱性については、悪用につながる詳細を公開Issueに投稿しないでください。
